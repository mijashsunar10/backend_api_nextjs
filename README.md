prisma (The Architect): It's a tool you use to design and build your database structure (tables, columns, etc.).
@prisma/client (The Bridge): It's a code library (generated by Prisma) that lets your Next.js app talk to your database (write queries, fetch data).
bcryptjs (The Locksmith): It's a tool for securely storing passwords. It scrambles them (hashes) so even if someone steals your database, they can't read the plain passwords.
jsonwebtoken (The Key Master): It's used to create and verify "tokens". Tokens are like digital keys that prove who a user is after they log in, allowing you to control what they can access.
